### 2.  nullptr 关键字

**`nullptr`** 是 C++11 引入的一个关键字，用于表示空指针。它解决了 C++ 中传统空指针表示方式（如 `NULL` 或 `0`）带来的类型安全问题和潜在的二义性。在 C++11 之前，程序员通常使用 `NULL` 或 `0` 来表示空指针。然而，这两种方式存在以下问题：

1. **类型不安全**：`NULL` 通常被定义为 `0` 或 `((void*)0)`，但它本质上是一个整数常量，而不是指针类型。这可能导致类型推导错误或意外的函数重载解析。
2. **二义性**：在某些情况下，`NULL` 或 `0` 可能会被错误地解释为整数类型，而不是指针类型，从而导致代码行为不符合预期。

```cpp
void f(int);        // 重载函数，接受 int 类型参数
void f(void*);      // 重载函数，接受 void* 类型参数

f(0);               // 调用 f(int)，因为 0 是整数类型
f(NULL);            // 调用 f(int)，如果 NULL 定义为 0；否则可能产生歧义
f(nullptr);         // 调用 f(void*)，因为 nullptr 是明确的空指针类型
```

### 3. auto 关键字

C++11 及其后续版本中，`auto` 关键字被引入以**简化变量的类型声明**。使用 `auto` 编译器会**自动推断变量的类型**，这样可以减少代码量并提高可读性。

```Cpp
auto x = 10;        // x的类型被推断为int
auto y = 3.14;      // y的类型被推断为double
auto str = "Hello"; // str的类型被推断为const char*
```

`auto` 适用于 **某些类型（如设备指针、迭代器、模板类型等**）非常冗长或复杂的情况。

- **简化复杂类型声明**：使用 `auto` 可以避免冗长的类型声明；在 for 循环中，`auto` 可以自动推导容器元素的类型

```Cpp
std::vector<int> vec = {1, 2, 3};
auto it = vec.begin(); // 自动推导为 std::vector<int>::iterator

for (auto val : vec) { // val 自动推导为 int
    std::cout << val << " ";
}
```

- **Lambda 表达式**：Lambda 表达式的类型是编译器生成的，无法显式写出，因此 `auto` 是存储 lambda 表达式的唯一方式

```Cpp
auto lambda = [](int x) { return x * 2; };
std::cout << lambda(5); // 输出 10
```

- **模板编程**：`auto` 可以用于推导模板参数的类型

```Cpp
template<typename T, typename U>
auto add(T a, U b) -> decltype(a + b) {
    return a + b;
}

auto result = add(3, 4.5); // 自动推导为 double
```

- **避免类型截断**：使用 `auto` 可以避免隐式类型转换导致的截断问题

```Cpp
int x = 5;
double y = 3.14;
auto z = x + y; // z 自动推导为 double，避免截断
```

### 4. 统一初始化

**统一初始化（Uniform Initialization）** 是 C++11 引入的一种初始化语法，旨在提供一种统一的、一致的初始化方式，适用于所有类型（如基本类型、数组、结构体、类等）。它使用花括号 `{}` 进行初始化，避免了传统初始化方式中的一些歧义和问题。以下是其使用场景和与传统初始化方式的对比。

**传统初始化方法**：

```Cpp
Rect rl = {3, 7, 20, 25, &area, &print};
Rect r1(3, 7, 20, 25);
int ia[6] = {27, 210, 12, 47, 109, 83};
```

**统一初始化方法**：

```Cpp
int x{10};       // 初始化 int
double y{3.14};  // 初始化 double

int arr[]{1, 2, 3};  // 初始化数组

struct Point {
    int x, y;
};

Point p{1, 2};  // 初始化结构体

std::vector<int> v{1, 2, 3};  // 初始化 vector
std::map<int, std::string> m{{1, "one"}, {2, "two"}};  // 初始化 map

int x{3.14};  // 错误：窄化转换
int y(3.14);  // 允许：隐式转换，y = 3

std::vector<int> v{1, 2, 3};  // 使用 initializer_list 初始化

std::vector<int> v{10, 20};  // 2 个元素：10, 20
std::vector<int> v(10, 20);  // 10 个元素，每个值为 2
```

**与传统初始化方式的对比**

|初始化方式|语法|适用场景|问题|
|---|---|---|---|
|传统初始化|`T obj(arg1, arg2)`|构造函数调用|最令人烦恼的解析|
|赋值初始化|`T obj = value`|简单类型初始化|不支持复杂类型|
|统一初始化|`T obj{arg1, arg2}`|所有类型，避免歧义和窄化转换|构造函数重载可能冲突|

### 5. 初始化列表

**初始化列表（Initializer List）**

在C++11中，**初始化列表（Initializer List）** 提供了一种简洁且强大的方式来初始化变量或指针类型。使用大括号`{}`进行初始化时，若未指定值，则默认初始化为0或`nullptr`。

```C++
int i;    // i 的值未定义
int j{};  // j 被初始化为 0
int* p;   // p 的值未定义
int* q{}; // q 被初始化为 nullptr
```

**使用`std::initializer_list<>`模板类**

C++11引入了`std::initializer_list<>`模板类，它允许处理一系列值。以下是一个使用`std::initializer_list<>`作为函数参数的示例：

```C++
void print(std::initializer_list<int> vals) {
    // 遍历 initializer_list
    for (auto p = vals.begin(); p != vals.end(); ++p) {
        std::cout << *p << "\n";
    }
}

print({12, 3, 5, 7, 11, 13, 174}); //传递一个初始化列表
```

**类中的初始化列表构造函数**

在类中，可以通过`std::initializer_list<>`来定义构造函数，从而支持使用大括号进行初始化：

```C++
#include <iostream>
#include <initializer_list>

class P {
public:
    // 普通构造函数
    P(int a, int b) {
        std::cout << "P(int, int), a=" << a << ", b=" << b << std::endl;
    }

    // std::initializer_list 构造函数
    P(std::initializer_list<int> initlist) {
        std::cout << "P(std::initializer_list<int>), values=";
        for (auto i : initlist) {
            std::cout << i << " ";
        }
        std::cout << std::endl;
    }
};

int main() {
    // 使用不同初始化语法调用构造函数
    P p(77, 5);       // 调用普通构造函数
    P q{77, 5};       // 调用 std::initializer_list 构造函数
    P r{77, 5, 42};   // 调用 std::initializer_list 构造函数
    P s = {77, 5};    // 调用 std::initializer_list 构造函数

    return 0;
}
```

- 如果类中定义了`std::initializer_list<>`构造函数，使用大括号`{}`初始化时，会优先调用该构造函数。
- 如果没有定义`std::initializer_list<>`构造函数，编译器会尝试将大括号中的值拆解为普通构造函数的参数。如果参数数量不匹配，则会导致编译错误
  
**容器与算法中的`initializer_list`**

C++11之后，所有的容器和算法都支持使用`initializer_list`进行构造、拷贝和赋值操作：

![](../../../images/C&C++/Pasted%20image%2020250317114347.png)

```C++
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

int main() {
    // 使用 std::initializer_list 初始化 vector
    std::vector<int> v1{ 2, 5, 7, 13, 69, 83, 50 };
    std::vector<int> v2({ 2, 5, 7, 13, 69, 83, 50 });

    std::vector<int> v3;
    v3 = { 2, 5, 7, 13, 69, 83, 50 };

    // 插入元素到 vector 中
    v3.insert(v3.begin() + 2, { 0, 1, 2, 3, 4 });

    for (auto i : v3) {
        std::cout << i << " ";
    }
    std::cout << std::endl;

    // 使用 max 和 min 函数处理 initializer_list
    std::cout << std::max({ std::string("Ace"), std::string("stacy"), std::string("sabrina"), std::string("Barkley") }) << std::endl; // stacy
    std::cout << std::min({ std::string("Ace"), std::string("stacy"), std::string("sabrina"), std::string("Barkley") }) << std::endl; // Ace
    std::cout << std::max({ 54, 16, 48, 5 }) << std::endl;
    std::cout << std::min({ 54, 16, 48, 5 }) << std::endl;

    return 0;
}
```

**C++11 之后：**

C++11 扩展了 `explicit` 关键字的使用范围，使其能够用于多参数的构造函数。这样可以更灵活地控制类型转换行为，避免不必要的隐式转换

### 7. Range-based for 循环

C++11 引入了 **Range-based for 循环**，它提供了一种简洁的方式来遍历容器或数组中的元素。其基本语法如下：

```C++
for (decl : coll) {
    statement;
}
```

其中：

- `decl` 是当前遍历元素的声明（类型可以是值类型或引用类型）。
- `coll` 是需要遍历的容器或数组。
- `statement` 是对每个元素执行的操作。

**示例 1：遍历初始化列表**

```C++
for (int i : {1, 2, 3, 4, 5, 6}) {
    cout << i << endl;
}
```

这段代码会依次输出 `1` 到 `6` 的值。

**示例 2：遍历 `std::vector`**

```C++
vector<int> vec;
// 假设 vec 已经被初始化并填充数据
for (auto elem : vec) {
    cout << elem << endl;
}
```

这段代码会依次输出 `vec` 容器中的每个元素。

**示例 3：使用引用修改容器元素**

```C++
for (auto &elem : vec) {
    elem *= 3;
}
```

通过使用引用 `&elem`，可以直接修改容器中的元素。例如，这段代码会将 `vec` 中的每个元素乘以 3。

### 8. 删除默认构造函数和删除赋值构造函数

如果你自行定义了一个构造函数（ctor），那么编译器将不再为你提供默认构造函数（default ctor）。  
如果你强制加上 `= default`，就可以重新获得并使用默认构造函数。

```C++
class Zoo {
public:
    Zoo(int i1, int i2) : d1(i1), d2(i2) { }  // 自定义构造函数
    Zoo(const Zoo&) = delete;                 // 删除拷贝构造函数
    Zoo(Zoo&&) = default;                     // 默认移动构造函数
    Zoo& operator=(const Zoo&) = default;     // 默认拷贝赋值运算符
    Zoo& operator=(const Zoo&&) = delete;     // 删除移动赋值运算符
    virtual ~Zoo() {}                         // 虚析构函数

private:
    int d1, d2;                               // 私有成员变量
};
```

### 9. Alias template 模板别名

在 C++ 中，`using` 关键字可以用来为模板类创建一个别名，从而简化代码的书写。这种技术被称为 **模板别名（Alias Template）** 。模板别名的主要作用是提高代码的可读性和复用性，但它也有一些限制：**不能对模板别名进行特化或偏特化** 。

**示例代码**：以下是一个简单的模板别名示例：

```C++
template <typename T>
using Vec = std::vector<T, MyAlloc<T>>;

Vec<int> coll;  // 等价于 std::vector<int, MyAlloc<int>> coll;
```

在这个例子中，我们通过 `using` 定义了一个模板别名 `Vec`，它表示使用自定义分配器 `MyAlloc` 的 `std::vector`。这样，每次需要声明一个带有特定分配器的 `std::vector` 时，可以直接使用 `Vec<int>`，而无需重复写冗长的模板参数。

**迭代器类型萃取与容器操作**

在 C++ 中，可以通过 **迭代器类型萃取机制** （Iterator Traits）从容器中提取出其内部的值类型（value type）。这在编写泛型代码时非常有用，因为它允许我们以统一的方式处理不同类型的容器。

以下是一个完整的示例，展示了如何利用迭代器类型萃取来操作容器：

```C++
#include <iostream>
#include <vector>
#include <list>
#include <deque>
#include <iterator>

// 假设 SIZE 是一个常量，用于控制插入元素的数量
constexpr size_t SIZE = 10;

// 泛型函数，用于测试容器的移动语义
template <typename Container>
void test_moveable(Container c) {
    // 使用迭代器类型萃取获取容器的值类型
    using ValueType = typename std::iterator_traits<typename Container::iterator>::value_type;

    // 向容器中插入 SIZE 个默认构造的元素
    for (size_t i = 0; i < SIZE; ++i) {
        c.insert(c.end(), ValueType());
    }

    // 输出容器的第一个元素（假设容器非空）
    if (!c.empty()) {
        std::cout << "First element: " << *(c.begin()) << std::endl;
    }

    // 测试容器的拷贝和移动语义
    Container c1(c);           // 拷贝构造
    Container c2(std::move(c)); // 移动构造
    c1.swap(c2);               // 交换内容
}

// 示例调用
int main() {
    test_moveable(std::list<int>());
    test_moveable(std::vector<int>());
    test_moveable(std::deque<int>());
    return 0;
}
```


### 10.  Template template parameter 模板模板参数

**模板模板参数** 是 C++ 中一种高级的模板编程技术，允许将一个模板作为另一个模板的参数。这种技术在需要对容器或其他模板类进行泛型操作时非常有用。

由于某些容器（如 `std::vector` 或 `std::list`）可能需要多个模板参数（例如元素类型和分配器），直接使用模板模板参数可能会导致推导失败。为了解决这个问题，我们可以结合 **模板别名（Alias Template）** 来简化参数的推导过程。

**示例代码**：

```C++
#include <iostream>
#include <vector>
#include <list>
#include <deque>

// 假设 SIZE 是一个常量，用于控制插入元素的数量
constexpr size_t SIZE = 10;

// 定义一个模板别名，简化容器的声明
template <typename T>
using MyContainer = std::vector<T>;

// 模板模板参数示例
template <typename T, template <typename> class Container>
class XCls {
private:
    Container<T> c; // 使用模板模板参数定义的容器

public:
    // 构造函数：向容器中插入 SIZE 个默认构造的元素
    XCls() {
        for (size_t i = 0; i < SIZE; ++i) {
            c.insert(c.end(), T());
        }
    }

    // 输出容器的第一个元素（假设容器非空）
    void printFirstElement() const {
        if (!c.empty()) {
            std::cout << "First element: " << *(c.begin()) << std::endl;
        } else {
            std::cout << "Container is empty!" << std::endl;
        }
    }

    // 测试容器的拷贝和移动语义
    void testMoveSemantics() {
        Container<T> c1(c);           // 拷贝构造
        Container<T> c2(std::move(c)); // 移动构造
        c1.swap(c2);                  // 交换内容
    }
};

// 示例调用
int main() {
    XCls<int, MyContainer> obj; // 使用模板别名 MyContainer
    obj.printFirstElement();
    obj.testMoveSemantics();
    return 0;
}
```

通过这种方式，我们可以避免直接在模板模板参数中处理复杂的多参数容器（如 `std::vector<T, Allocator>`）

### 11.  Type Alias 类型别名

在 C++ 中，**类型别名** 是一种为现有类型定义新名称的机制。它可以通过两种方式实现：传统的 `typedef` 和现代的 `using` 关键字。虽然两者功能相似，但在模板编程中，`using` 提供了更高的灵活性和可读性。

**示例代码**：

```C++
// 使用 using 定义函数指针类型别名
using Func = void (*)(int, int); // 等价于 typedef void (*Func)(int, int);

// 示例函数
void example(int a, int b) {
    std::cout << "Sum: " << (a + b) << std::endl;
}

// 定义并使用函数指针
Func fn = example; // 将 example 函数赋值给函数指针 fn
fn(3, 4);          // 调用函数，输出 Sum: 7

// 在类中定义类型别名
template <typename T>
struct Container {
    using value_type = T; // 等价于 typedef T value_type;
};

// 示例：访问类中的类型别名
Container<int>::value_type x = 42; // value_type 是 int 的别名
std::cout << "Value: " << x << std::endl;

// 使用模板别名隐藏模板参数
template <class CharT>
using MyString = std::basic_string<CharT, std::char_traits<CharT>>;

// 示例：使用模板别名简化复杂类型
MyString<char> str = "Hello, World!";
std::cout << "String: " << str << std::endl;
```

### 12. noexcept 关键字

`noexcept` 是一个非常重要的关键字，用于声明函数不会抛出异常。

- **作用**：在函数声明后加上 `noexcept`，可以明确表示该函数不会抛出任何异常。- 如果函数违反了 `noexcept` 的承诺（即抛出了异常），程序会调用 `std::terminate()`，默认行为是终止程序。
- **条件性 `noexcept`** ：可以通过 `noexcept(expression)` 来指定某种条件下函数不会抛出异常。`expression` 的结果为 `true` 时，函数被视为 `noexcept`；否则，函数可能抛出异常。

**示例代码**：

```C++
// 声明一个不会抛出异常的函数
void foo() noexcept {
    // 函数体
}

// 条件性 noexcept：只有当 x.swap(y) 不抛出异常时，swap 函数也不会抛出异常
template <typename T>
void swap(T& x, T& y) noexcept(noexcept(x.swap(y))) {
    x.swap(y);
}

// 移动构造函数和移动赋值运算符
class MyString {
private:
    char* data;
    size_t len;

public:
    // 移动构造函数
    MyString(MyString&& str) noexcept 
        : data(str.data), len(str.len) {
        str.data = nullptr;
        str.len = 0;
    }

    // 移动赋值运算符
    MyString& operator=(MyString&& str) noexcept {
        if (this != &str) {
            delete[] data; // 释放当前资源
            data = str.data;
            len = str.len;
            str.data = nullptr;
            str.len = 0;
        }
        return *this;
    }
};
```

标准库容器（如 `std::vector`）在扩容时，会尝试调用对象的移动构造函数或移动赋值运算符。如果这些函数未标记为 `noexcept`，容器可能会认为移动操作不安全，从而回退到使用拷贝操作。因此，在实现自定义类时，建议将移动构造函数和移动赋值运算符标记为 `noexcept`，**以充分利用移动语义带来的性能优势**。

### 13. override 关键字

`override` 用于显式声明子类重写了父类的虚函数。它的主要作用是帮助开发者避免因函数签名错误而导致的意外行为。

在子类中重写父类的虚函数时，使用 `override` 关键字可以明确表示该函数是从父类继承而来的。如果子类的函数签名与父类的虚函数不匹配（例如参数类型或返回值不同），编译器会报错，从而避免潜在的错误。

**示例代码**：

```C++
struct Base {
    virtual void vfunc(float) {
        std::cout << "Base::vfunc(float)" << std::endl;
    }
};

// 错误示例：未使用 override，导致签名错误
struct Derived1 : Base {
    virtual void vfunc(int) { // 参数类型错误，编译器不会报错
        std::cout << "Derived1::vfunc(int)" << std::endl;
    }
};

// 正确示例：使用 override 捕获签名错误
struct Derived2 : Base {
    virtual void vfunc(int) override { // 编译器会报错：签名不匹配
        std::cout << "Derived2::vfunc(int)" << std::endl;
    }
};

// 正确示例：正确重写父类虚函数
struct Derived3 : Base {
    virtual void vfunc(float) override { // 正确重写，编译通过
        std::cout << "Derived3::vfunc(float)" << std::endl;
    }
};
```

### 14. final 关键字

`final` 用于限制类的继承或虚函数的重写

```C++
// 1. 类的 final：禁止继承
struct Base1 final {
    void func() {
        std::cout << "Base1::func()" << std::endl;
    }
};

// struct Derived1 : Base1 {}; // 编译错误：Base1 是 final，不能被继承

// 2. 虚函数的 final：禁止重写
struct Base2 {
    virtual void f() final {
        std::cout << "Base2::f()" << std::endl;
    }
};

struct Derived2 : Base2 {
    // void f() override {} // 编译错误：Base2::f 是 final，不能被重写

struct Base3 {
    virtual void g() {}
};

struct Derived3 : Base3 {
    void g() override final { // 禁止进一步重写
        std::cout << "Derived3::g()" << std::endl;
    }
};
```

### 15. decltype 关键字

使用 `decltype` 用于推导表达式的类型，主要有三种应用场景：

1. 声明返回值类型；
2. 模板元编程中推导类型；
3. 传递 lambda 表达式的类型

```C++
#include <map>
#include <string>
#include <set>

// 示例 1：使用 decltype 声明变量类型
std::map<std::string, float> coll;
decltype(coll)::value_type elem; // 等价于 std::pair<const std::string, float>

// 示例 2：模板函数中使用 decltype 推导返回值类型
template <typename T1, typename T2>
auto add(T1 x, T2 y) -> decltype(x + y) {
    return x + y;
}

// 示例 3：模板元编程中使用 decltype
template <typename T>
void test_decltype(const T& obj) {
    using ValueType = typename decltype(obj)::value_type; // 获取容器的 value_type
    using IteratorType = typename decltype(obj)::iterator; // 获取容器的 iterator 类型

    decltype(obj) anotherObj = obj; // 使用 decltype 复制对象
}

// 示例 4：使用 decltype 推导 lambda 表达式的类型
struct Person {
    std::string firstname;
    std::string lastname;

    bool operator<(const Person& other) const {
        return lastname < other.lastname || (lastname == other.lastname && firstname < other.firstname);
    }
};

int main() {
    auto cmp = [](const Person& p1, const Person& p2) {
        return p1.lastname < p2.lastname || (p1.lastname == p2.lastname && p1.firstname < p2.firstname);
    };

    // 使用 decltype 推导 lambda 表达式的类型
    std::set<Person, decltype(cmp)> coll(cmp);

    coll.insert(Person{"John", "Doe"});
    coll.insert(Person{"Jane", "Smith"});

    for (const auto& person : coll) {
        std::cout << person.firstname << " " << person.lastname << std::endl;
    }

    return 0;
}
```

- 示例 1 中，使用 `decltype(coll)` 获取 `coll` 的类型，并通过 `::value_type` 提取其元素类型；
- 示例 2 中，`decltype(x + y)` 用于推导 `x + y` 的结果类型，并将其作为模板函数的返回值类型；
- 示例 3 中，`decltype` 被用来提取容器的 `value_type` 和 `iterator` 类型
- 示例 4 中，`decltype(cmp)` 被用来推导 lambda 表达式的类型，并将其作为 `std::set` 的比较函数类型

### 16. Lambda 表达式

**Lambda 表达式** 是一种用于创建匿名函数对象的便捷工具。它允许开发者以内联的方式定义函数逻辑，而**无需显式声明函数或函数对象**

 $$
[捕获列表](参数列表) mutable(可选) throwSpec(可选) -> 返回类型(可选) { 函数体 }
$$

- **捕获列表** ：指定 Lambda 表达式如何访问外部变量（按值或按引用）。
- **参数列表** ：指定 Lambda 表达式的输入参数。
- **mutable** （可选）：允许修改按值捕获的外部变量。
- **返回类型** （可选）：显式指定返回类型；如果省略，编译器会自动推导。
- **函数体** ：Lambda 表达式的具体实现逻辑。

**捕获模式** ： 

- `[=]`：按值捕获所有外部变量。
- `[&]`：按引用捕获所有外部变量。
- `[x, &y]`：按值捕获 `x`，按引用捕获 `y`。
- `[this]`：捕获当前类的 `this` 指针。

**示例代码**

```C++
#include <iostream>
#include <vector>
#include <algorithm>

// 示例 1：简单的 Lambda 表达式
int main() {
    // 定义并立即调用一个 Lambda 表达式
    [] {
        std::cout << "Hello, Lambda!" << std::endl;
    }();

    // 将 Lambda 表达式赋值给变量
    auto l = [] {
        std::cout << "Hello, Lambda!" << std::endl;
    };

    // 调用存储的 Lambda 表达式
    l();
}

// 示例 2：捕获外部变量
int id = 0;

auto f = [id]() mutable {
    std::cout << "ID: " << id << std::endl;
    ++id; // 修改按值捕获的变量
};

f(); // 输出 ID: 0
std::cout << "External ID: " << id << std::endl; // 外部变量未改变

// 示例 3：捕获引用
id = 42;

auto g = [&id]() {
    std::cout << "ID: " << id << std::endl;
    ++id; // 修改外部变量
};

g(); // 输出 ID: 42
std::cout << "External ID: " << id << std::endl; // 外部变量已改变

// 示例 4：结合 STL 算法
std::vector<int> vi = {5, 28, 50, 83, 70, 590, 245, 59, 24};
int x = 30;
int y = 100;

// 使用 Lambda 表达式过滤范围内的元素
vi.erase(std::remove_if(vi.begin(), vi.end(),
    [x, y](int n) { return x < n && n < y; }), vi.end());

for (auto i : vi) {
    std::cout << i << " "; // 输出：5 28 590 245 24
}
std::cout << std::endl;
```

- 示例 1 中，定义了一个无参数、无返回值的 Lambda 表达式，并立即调用它
- 示例 2 中，`id` 被按值捕获。由于添加了 `mutable` 关键字，Lambda 表达式可以修改捕获的变量副本，但不会影响外部变量。
- 示例 3 中，`id` 被按引用捕获。Lambda 表达式可以直接修改外部变量。
- 示例 4 中，使用 Lambda 表达式作为谓词，结合 `std::remove_if` 删除范围内的元素

### 17.  Variadic Templates 可变参数模板
 
**可变参数模板（Variadic Templates）** 是 C++11 引入的一项强大特性，它允许**类模板**或**函数模板**接受**任意数量的模板参数**。通过使用 `typename...` 或 `class...` 声明模板参数包，可以轻松处理不确定数量的参数。

可变参数模板变化的是**参数类型**和**参数个数**，声明如下：

```C++
template <typename T, typename... Types>
void func(const T& firstArg, const Types&... args) {
    // 处理第一个参数
    std::cout << "First argument: " << firstArg << std::endl;
    // 递归处理剩余参数
    func(args...);
}
```

#### 17.1. 示例代码1

```Cpp
#include <iostream>
#include <bitset>

using namespace std;

// 基础版本：递归终止条件
void print() {
    cout << "End of recursion" << endl;
}

// 递归版本：处理第一个参数并递归调用剩余参数
template<typename T, typename... Types>
void print(const T& firstArg, const Types&... args) {
    cout << "Number of remaining arguments: " << sizeof...(args) << endl; // 打印剩余参数个数
    cout << "Current argument: " << firstArg << endl;
    print(args...); // 递归调用
}

int main() {
    // 调用 print 函数，传递多个不同类型的参数
    print(7.5, 42, 2.5, "Hello", 'A', bitset<16>(377));
    return 0;
}
```

```shell
Number of remaining arguments: 5
Current argument: 7.5
Number of remaining arguments: 4
Current argument: 42
Number of remaining arguments: 3
Current argument: 2.5
Number of remaining arguments: 2
Current argument: Hello
Number of remaining arguments: 1
Current argument: A
Number of remaining arguments: 0
Current argument: 0000000101111001
End of recursion
```

**可变参数模板的核心优势在于其递归调用的灵活性**。在上述代码中，`print` 函数通过递归和可变参数模板，实现了对任意数量、任意类型参数的打印。每次递归调用时，参数包的大小逐渐减少，直到为空时递归终止。

从 C++17 开始，可以通过 **折叠表达式** 简化可变参数模板的实现。例如，计算多个参数的总和：

```C++
#include <iostream>

// 使用折叠表达式求和
template<typename... Args>
auto sum(Args... args) {
    return (args + ...); // 折叠表达式：从左到右累加
}

int main() {
    std::cout << "Sum: " << sum(1, 2, 3, 4, 5) << std::endl; // 输出 Sum: 15
    return 0;
}
```

![](../../../images/C&C++/Pasted%20image%2020250226143940.png)

**可变参数模板有以下几个特点**：

- **模板特化**：当存在多个模板参数函数时，编译器会优先选择**最特化的版本**进行调用，如 `template<typename T, typename... Types>` 和 `template< typename... Types>`。
- **递归继承**：可变参数模板可以用于实现递归继承，这在某些设计模式中非常有用。

#### 17.2. 示例代码2：重写 `printf` 函数

使用可变参数模板（Variadic Templates）来模拟 C 风格的 `printf` 函数。

```C++
#include <iostream>
#include <stdexcept>

// 基础版本：递归终止条件
void printf(const char* s) {
    while (*s) {
        if (*s == '%' && *(s + 1) != '%') {
            throw std::logic_error("Invalid format string: missing arguments");
        }
        std::cout << *s++;
    }
}

// 递归版本：处理格式字符串和参数
template<typename T, typename... Args>
void printf(const char* s, T value, Args... args) {
    while (*s) {
        if (*s == '%' && *(s + 1) != '%') {
            std::cout << value; // 输出当前参数
            printf(++s, args...); // 递归处理剩余参数
            return;
        }
        std::cout << *s++;
    }
    throw std::logic_error("Extra arguments provided to printf");
}

int main() {
    // 测试 printf 函数
    printf("Hello, %s! The answer is %d.\n", "world", 42);
    printf("Floating point: %.2f\n", 3.14159);
    printf("No arguments here.\n");

    // 错误示例：格式字符串与参数不匹配
    try {
        printf("Mismatched arguments: %d %s\n", 42);
    } catch (const std::logic_error& e) {
        std::cerr << "Error: " << e.what() << std::endl;
    }

    return 0;
}
```

```shell
Hello, world! The answer is 42.
Floating point: 3.14
No arguments here.
Error: Extra arguments provided to printf
```

#### 17.2. 示例代码3： 利用可变参数模板实现 `max` 函数

标准库提供了 `std::max` 函数来比较两个值并返回较大的一个。然而，通过结合 **可变参数模板** 和 **初始化列表（`std::initializer_list`）** ，我们可以进一步扩展 `max` 的功能，使其能够处理任意数量的参数。

```C++
#include <iostream>
#include <algorithm> // std::max_element
#include <iterator>  // std::begin, std::end
#include <initializer_list>

// 基础版本：处理两个参数
template<typename T>
T max(T a, T b) {
    return (a > b) ? a : b;
}

// 扩展版本：处理任意数量的参数
template<typename T, typename... Args>
T max(T first, Args... args) {
    T result = first;
    ((result = max(result, args)), ...); // 折叠表达式逐个比较
    return result;
}

// 使用 initializer_list 处理数组或集合
template<typename T>
T max(std::initializer_list<T> list) {
    if (list.size() == 0) {
        throw std::invalid_argument("Empty initializer list");
    }
    return *std::max_element(list.begin(), list.end());
}

int main() {
    // 测试 max 函数
    std::cout << "Max of two values: " << max(57, 48) << std::endl;

    // 测试多个参数
    std::cout << "Max of multiple values: " << max(57, 48, 60, 100, 20, 18) << std::endl;

    // 测试 initializer_list
    std::initializer_list<int> numbers = {57, 48, 60, 100, 20, 18};
    std::cout << "Max using initializer_list: " << max(numbers) << std::endl;

    return 0;
}
```

```shell
Max of two values: 57
Max of multiple values: 100
Max using initializer_list: 100
```

- 折叠表达式 `((result = max(result, args)), ...)` 是 C++17 引入的语法糖，用于简化对参数包的操作
- `std::max_element` 是 STL 中的一个算法，用于查找范围内的最大元素

#### 17.4. 示例代码 4：利用递归调用 `std::max` 实现 `maximum` 函数

在 C++ 中，标准库提供了 `std::max` 函数来比较两个值并返回较大的一个。通过结合 **可变参数模板** 和 **递归调用** ，我们可以实现一个通用的 `maximum` 函数，用于计算任意数量参数中的最大值。

```C++
#include <iostream>
#include <algorithm> // std::max

// 基础版本：处理单个参数
int maximum(int n) {
    return n; // 如果只有一个参数，直接返回该参数
}

// 扩展版本：处理多个参数
template<typename... Args>
int maximum(int n, Args... args) {
    return std::max(n, maximum(args...)); // 递归调用 maximum
}

int main() {
    // 测试 maximum 函数
    std::cout << "Maximum of multiple values: " 
              << maximum(57, 48, 60, 100, 20, 18) << std::endl;

    return 0;
}
```

```shell
Maximum of multiple values: 100
```

在每次递归调用中，`std::max` 被用来比较当前参数 `n` 和递归结果 `maximum(args...)`，从而逐步找到最大值。

#### 17.5. 示例代码 5：利用可变参数模板打印元组（`std::tuple`）

在 C++ 中，`std::tuple` 是一种用于存储多个不同类型的值的容器。通过结合 **可变参数模板** 和 **递归展开** ，我们可以实现一个通用的 `operator<<`，用于以特定格式输出元组中的元素。

```C++
#include <iostream>
#include <tuple>
#include <string>
#include <bitset>

// 重载 << 运算符，用于打印元组
template<typename... Args>
std::ostream& operator<<(std::ostream& os, const std::tuple<Args...>& t) {
    os << '[';
    print_tuple(os, t, std::index_sequence_for<Args...>{});
    os << ']';
    return os;
}

// 帮助函数：递归打印元组中的每个元素
template<std::size_t I, typename... Args>
struct print_tuple_helper {
    static void print(std::ostream& os, const std::tuple<Args...>& t) {
        os << std::get<I>(t);
        if constexpr (I + 1 < sizeof...(Args)) {
            os << ", ";
        }
        print_tuple_helper<I + 1, Args...>::print(os, t);
    }
};

// 递归终止条件
template<typename... Args>
struct print_tuple_helper<sizeof...(Args), Args...> {
    static void print(std::ostream&, const std::tuple<Args...>&) {}
};

// 调用帮助函数进行递归打印
template<typename... Args>
void print_tuple(std::ostream& os, const std::tuple<Args...>& t, std::index_sequence<>) {}

template<typename... Args, std::size_t... Is>
void print_tuple(std::ostream& os, const std::tuple<Args...>& t, std::index_sequence<Is...>) {
    (print_tuple_helper<Is, Args...>::print(os, t), ...);
}

int main() {
    // 测试打印元组
    auto tuple = std::make_tuple(7.5, std::string("hello"), std::bitset<16>(377), 42);
    std::cout << tuple << std::endl;

    return 0;
}
```

```shell
[7.5, hello, 00000000101111001, 42]
```

- 通过 `print_tuple_helper<sizeof...(Args), Args...>` 提供递归终止条件，确保不会无限递归
- `std::index_sequence` 和 `std::index_sequence_for` 是 C++14 引入的工具类，用于生成索引序列，从而简化递归操作。

#### 17.6. 示例代码 6：利用递归继承实现元组（`tuple`）

在 C++ 中，**递归模板** 是一种强大的技术，可以用于实现复杂的数据结构。通过结合 **可变参数模板** 和 **递归继承** ，我们可以手动实现一个类似于 `std::tuple` 的类，用于存储多个不同类型的值。


![](../../../images/C&C++/Pasted%20image%2020250226144050.png)

```C++
#include <iostream>
#include <type_traits>

// 基础版本：空元组
template<>
class tuple<> {
public:
    // 空元组没有成员
};

// 递归版本：处理非空元组
template<typename Head, typename... Tail>
class tuple<Head, Tail...> : private tuple<Tail...> {
private:
    Head m_head; // 存储当前元素
    using inherited = tuple<Tail...>; // 使用私有继承

public:
    // 默认构造函数
    tuple() = default;

    // 构造函数：初始化当前元素和剩余元素
    tuple(Head head, Tail... tail)
        : m_head(head), inherited(tail...) {}

    // 获取当前元素
    Head head() const { return m_head; }

    // 获取剩余元素
    inherited& tail() { return *this; }
};

int main() {
    // 测试自定义 tuple
    tuple<int, float, std::string> t(41, 6.3f, "nico");

    // 输出元组中的元素
    std::cout << "Head: " << t.head() << std::endl;
    std::cout << "Tail (next element): " << t.tail().head() << std::endl;
    std::cout << "Tail of tail: " << t.tail().tail().head() << std::endl;

    return 0;
}
```

```shell
Head: 41
Tail (next element): 6.3
Tail of tail: nico
```

- 基础版本定义了一个特化版本的 `tuple`，表示空元组。空元组没有存储任何数据。
- 使用递归继承：`tuple<Head, Tail...>` 私有继承 `tuple<Tail...>`。每个 `tuple` 对象存储当前元素 `m_head`，并通过私有继承存储剩余的元素。提供了 `head()` 方法获取当前元素，以及 `tail()` 方法获取剩余的元素。

#### 17.7. 示例代码 7：利用递归复合实现元组（`tup`）

在 C++ 中，**递归复合** 是一种通过组合多个模板实例来构建复杂数据结构的技术。通过结合 **可变参数模板** 和 **递归复合** ，我们可以手动实现一个类似于 `std::tuple` 的类，用于存储多个不同类型的值。

```C++
#include <iostream>
#include <type_traits>
#include <complex>
#include <bitset>

// 基础版本：空元组
template<>
class tup<> {
public:
    // 空元组没有成员
};

// 递归版本：处理非空元组
template<typename Head, typename... Tail>
class tup<Head, Tail...> {
private:
    Head m_head; // 存储当前元素
    using composed = tup<Tail...>; // 使用递归复合

protected:
    composed m_tail; // 存储剩余元素

public:
    // 默认构造函数
    tup() = default;

    // 构造函数：初始化当前元素和剩余元素
    tup(Head head, Tail... tail)
        : m_head(head), m_tail(tail...) {}

    // 获取当前元素
    Head head() const { return m_head; }

    // 获取剩余元素
    composed& tail() { return m_tail; }
};

int main() {
    // 测试自定义 tup
    tup<int, float, std::string> it1(41, 6.3f, "nico");

    // 输出元组中的元素
    std::cout << "Size of tuple: " << sizeof...(it1) << std::endl;
    std::cout << "Head: " << it1.head() << std::endl;
    std::cout << "Tail (next element): " << it1.tail().head() << std::endl;
    std::cout << "Tail of tail: " << it1.tail().tail().head() << std::endl;

    // 测试另一个复杂的元组
    tup<std::string, std::complex<int>, std::bitset<16>, double> it2(
        "Ace",
        std::complex<int>(3, 8),
        std::bitset<16>(377),
        3.141592653
    );

    // 输出元组中的元素
    std::cout << "Size of tuple: " << sizeof...(it2) << std::endl;
    std::cout << "Head: " << it2.head() << std::endl;
    std::cout << "Tail (next element): " << it2.tail().head() << std::endl;
    std::cout << "Tail of tail: " << it2.tail().tail().head() << std::endl;
    std::cout << "Tail of tail of tail: " << it2.tail().tail().tail().head() << std::endl;

    return 0;
}
```
